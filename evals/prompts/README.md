# 提示词变体候选

放 `*.txt` 在这里，`node scripts/prompt-ab.cjs` 会把每个文件当一"臂"跑一遍评测
（用 `AURAXIS_PROMPT_VARIANT_FILE` 注入），并与基线臂对比通过率与 token 消耗。

一个变体 = 一段**追加**在系统提示词末尾的文本。写什么取决于你想验证的假设，例如：

- 要求先复述任务再动手 → 看是否减少误解任务导致的返工；
- 要求改完必须跑一次验证命令 → 看过程门槛 `verify-before-done` 的通过率；
- 要求用中文总结 → 看语义判分（`answer_judge`）里的相关条目。

约定：

- 一个文件只放一个假设，别把三件事混在一起 —— 混了就分不清是哪一条起了作用。
- 变体只影响**动态部分**（无头路径拼在 system prompt 末尾；Chat 路径插在缓存前缀之后的
  第 4 条消息），不会改动 `STATIC_SYSTEM_PROMPT`。
- 别把易过拟合的技巧写进来（"输出必须以 X 开头"这类只对当前数据集有效的规则）。

本目录里的变体不会自动生效，也不会自动被采纳：评测只产出可比的数据，决定由人做。
